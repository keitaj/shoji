こもれび商店

数の限られた品を、欲しい人に1つずつ届けるお店です。会員登録はありません。

1人1点まで：購入のときに、マイナンバーカードで「実在する1人」であることを確認します。 レビューは購入者だけ、1人1件：氏名も住所も、お店には届きません。

iPhone のカメラで QR コードを読み取り、shoji のアプリでマイナンバーカードをかざしてください。

お店に届くのは、確認の結果と、このお店専用の匿名 ID だけです。
カードなしで試す（開発者向け） 模擬の認証局を信頼する検証サーバで動かしている場合は、次のリンクを go run ./cmd/mockclient -link に渡します。
